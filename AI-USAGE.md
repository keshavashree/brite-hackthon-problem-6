# AI Usage

This project was developed using a pair-programming workflow between a human developer and an agentic AI coding assistant (Google DeepMind's Antigravity).

## AI Assistant Roles

The AI coding assistant contributed to:
- **System Design & Scaffolding**: Brainstorming code structures, component separation, and file organizations.
- **Implementation & Refactoring**: Writing the code for features, threshold-based signals, explanations, and feedback adjustment matrices.
- **Test Generation**: Scaffolding automated test cases for edge cases, missing data, and pipeline integration.
- **Governance Audit design**: Co-authoring the demographic fairness selection-ratio reporting scripts.
- **Documentation**: Assisting with framing `DECISIONS.md` and the user-facing pipeline summaries.

## Human Control & Responsibility

- All code structure decisions, weights, threshold selection, and boundaries were directed and vetted by the human developer.
- All code changes were reviewed, debugged, and run locally in interactive terminals.
- The human developer holds final accountability for the correctness, fairness, and safety boundaries of the submission.
