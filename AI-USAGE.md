# AI Usage

AI tools are being used during development of this project.

## Current Uses

- Project architecture brainstorming
- Data-analysis planning
- Feature-engineering discussion
- Code scaffolding
- Debugging assistance
- Test-case suggestions
- Documentation review

## Responsibility

All generated code and suggestions are reviewed, tested and understood
before being included in the final repository.

The author is responsible for the final implementation and must be
able to explain the system during evaluation.
