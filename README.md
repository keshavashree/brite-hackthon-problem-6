# Brite Spark 2026 — Problem 6

## The Overpayment Signal

An explainable investigation-prioritisation system for identifying
benefit cases that may warrant human review.

## Problem

The system produces a ranked worklist of the 20 cases most worth
an investigator reviewing.

Each ranked case includes a plain-language explanation based on
the underlying payment and case data.

## Current Status

🚧 Development in progress.

## Project Structure

- `data/` — supplied case and payment data
- `src/` — application source code
- `tests/` — automated tests
- `notebooks/` — exploratory analysis
- `output/` — generated results

## Important Boundary

This system is an investigation-prioritisation tool.

A ranking does not establish that a payment is improper and must
not automatically change, suspend, terminate, reduce, or recover
benefits.
